## Overview
This repository contains the design files for the OpenBook project, an open-source e-book reader. The project involves designing the PCB, integrating various components such as the ESP32-C6 module, battery, display, and case, and ensuring all parts fit within the provided enclosure.

## Repository Structure
```
- Hardware
  - schematic (.sch)
  - board file (.brd)

- Manufacturing
  - gerbers.zip
  - Bill of Materials (.bom)
  - Pick and Place (.cpl)

- Mechanical
  - 3D complete device (.step)
  - Fusion 360 design file (.f3d)

- Images
  - Rendered images of the device, PCB, etc.

- LICENSE
- README.md
```

## Components Used
- ESP32-C6 Module
- Battery
- Display
- Case
- Various SMD components (resistors, capacitors, etc.)

## How to Build
1. Clone the repository.
2. Open the `.f3z` file in Fusion 360.
3. Follow the manufacturing instructions to generate necessary files.
4. Verify and assemble the components according to the guidelines.
